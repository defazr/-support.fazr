objection-qa-2026

포함 질문:
1. 이의신청 기간은 언제까지인가요?
2. 이의신청은 어디서 하나요?
3. 보험료 초과는 무슨 뜻인가요?
4. 3월 성과급 때문에 건보료가 올랐으면 이의신청 가능한가요?
5. 2026년 3월 30일 이후 기초수급자가 됐으면 이의신청 가능한가요?
6. 주소지만 같고 실제로 따로 사는 가족 때문에 탈락했다면 어떻게 하나요?
7. 소득은 평균인데 왜 보험료 초과로 비대상일 수 있나요?
8. 이의신청할 때 어떤 자료를 준비해야 하나요?

반드시 포함:
- 이의신청 기간: 2026년 5월 18일 09:00 ~ 7월 17일 18:00
- 온라인: 국민신문고
- 오프라인: 2026년 3월 30일 기준 주민등록상 주소지 관할 읍·면·동 주민센터
- 문의: 1670-2626, 1577-1000
- 보험료 초과는 가구원 합산 건강보험료가 기준액을 넘었다는 의미
- 성과급, 소득 변동, 기준일 이후 수급자 확정, 가구분리 사례는 단정하지 말고 "이의신청 대상이 될 수 있다"는 톤
- 실제 인정 여부는 접수기관 판단이라고 명시

## 4. 글 2: 건보료·가구원·중복 Q&A

추천 제목:
고유가 피해지원금 2차 신청 Q&A — 건보료, 가구원, 1차 중복 신청 기준

추천 slug:
health-insurance-household-duplicate-qa-2026

포함 질문:
1. 우리 가족 건강보험료는 어디서 확인하나요?
2. 직장가입자와 지역가입자 기준은 왜 다른가요?
3. 직장가입자와 지역가입자가 한 가구에 같이 있으면 어떻게 보나요?
4. 맞벌이 등 다소득원 가구는 어떻게 계산하나요?
5. 따로 사는 부모님도 가구원에 포함되나요?
6. 주소지가 달라도 배우자와 자녀는 같은 가구가 될 수 있나요?
7. 1차 때 받았으면 2차도 받을 수 있나요?
8. 3차 지급도 있나요?
9. 부모가 대상에서 제외되면 미성년 자녀도 못 받나요?
10. 국민비서 알림이 오면 자동 지급인가요?

반드시 포함:
- 1차 신청 및 지급자는 2차 중복 신청·지급 불가
- 2차는 건강보험료 본인부담금 기준
- 맞벌이 등 다소득원 가구는 가구원 수 +1명 기준 적용
- 2026년 3월 30일 기준 주민등록표상 동일 세대 원칙
- 주소지가 달라도 건강보험 피부양자인 배우자와 자녀는 같은 가구 가능
- 주소지가 다른 부모와 형제자매는 피부양자라도 별도 가구
- 가구 단위 판정이므로 부모가 제외되면 같은 가구의 미성년 자녀도 제외될 수 있음
- 국민비서 알림은 자동 지급이 아니며 별도 신청 필요
- 3차 추가 지급 계획 없음은 공식 발표 기준으로 신중하게 표현
- 혼합형 건보료 기준표와 다소득원 분류 기준은 공식 확인 후 반영

## 5. 글 3: 사용처·사용지역 Q&A

추천 제목:
고유가 피해지원금 사용처 Q&A — 주유소, 프랜차이즈, 다른 지역 사용 기준

추천 slug:
usage-area-stores-qa-2026

포함 질문:
1. 공임나라 같은 프랜차이즈 가맹점에서도 사용할 수 있나요?
2. 네이버 지도에 사용 가능 매장 표시가 있으면 믿어도 되나요?
3. 도 지역은 다른 시·군에서도 사용할 수 있나요?
4. 군인이 외박 나가서 다른 지역에서 쓸 수 있나요?
5. 주민등록 주소지와 실거주지가 다르면 어디서 사용하나요?
6. 기준일 이후 이사하면 지원금 금액이 바뀌나요?
7. 대형 테마파크나 대형 매장에서도 사용할 수 있나요?
8. 지역사랑상품권과 카드 사용지역 기준은 같은가요?
9. 카드깡, 현금화, 양도는 왜 안 되나요?

반드시 포함:
- 사용지역은 원칙적으로 주민등록상 주소지 기준
- 특별시·광역시는 해당 시 전체, 도 지역은 시·군 단위 제한 가능
- 기준일 이후 이사해도 지원금 금액은 기준일 당시 주소지 기준
- 사용지역 변경 가능 여부는 카드사·지자체 확인 필요
- 프랜차이즈라도 개별 가맹점이면 사용 가능성이 있으나 최종 여부는 실제 승인 기준
- 네이버 지도 사용 가능 표시는 참고자료이며 최종 결제 가능 보장은 아님
- 주유소는 연 매출과 관계없이 사용 가능하되, 대형매장과 단말기·사업자번호 공유 시 제한 가능
- 신용·체크·선불카드는 연 매출 30억원 이하 소상공인 업체 중심
- 지역사랑상품권은 지역사랑상품권 가맹점 기준
- 카드깡, 현금화, 타인 양도, 중고거래는 부정사용 위험

## 6. 실제 지식인 질문 원문 요약

반드시 아래 질문군을 반영한다.

### 이의신청
- 보험료 초과 뜻
- 3월 성과급으로 건보료가 일시적으로 오른 경우
- 기준일 이후 기초수급자 확정
- 타지역 거주 가족 때문에 가구 합산 탈락
- 평균 소득인데 보험료 초과로 비대상
- 가구분리 이의신청 자료

### 건보료·가구원·중복
- 피부양자인 부모가 따로 사는 경우
- 1차 수령자 2차 중복 여부
- 소비쿠폰 2차 탈락자와 고유가 지원금 가능성
- 다소득원 +1 기준
- 기준일 이후 세대분리 효과
- 부모가 못 받으면 미성년 자녀도 못 받는지
- 국민비서 알림이 대상 확정인지
- 3차 지급 계획 여부

### 사용처·카드
- 공임나라 사용 가능 여부
- 특정 매장 사용 가능 여부
- 도 지역 내 다른 시·군 사용 가능 여부
- 혁신도시 교차 사용 가능 여부
- 실거주지와 주민등록 주소지 불일치
- 기준일 이후 이사 시 금액 변경 여부
- 카드 재발급 후 잔액 유지
- NH Pay 잔액 확인
- 대리 신청
- 부정사용 기준
- 두 지원금 차감 순서

## 7. 작성 규칙

- 신규 글 작성 전 기존 updates 글 2~3개 raw HTML 패턴 audit
- prose 기반 기본 HTML 사용
- h2, h3, p, ul, li, table, strong 중심
- section, space-y, border-l, 카드형 CTA 남발 금지
- 수동 bullet 점 금지
- 상단 목차는 단순한 ul 또는 p 링크 형태
- 질문별 h3 id 부여
- 다음 행동은 기존 글처럼 인라인 링크
- 박스류는 기존 updates 글의 className 그대로 차용
- Q&A 글은 합니다체로 통일
- 보도형 했다체와 섞지 말 것
- raw URL 금지, 링크는 a 태그 처리
- 검색 결과 노출 보장 표현 금지

## 8. Q&A 글 분량 기준

### 글 전체 분량
- 글 1 이의신청 Q&A: 약 2,500~3,500자
- 글 2 건보료·가구원·중복 Q&A: 약 3,000~4,000자
- 글 3 사용처·사용지역 Q&A: 약 2,500~3,800자

너무 짧으면 정보성이 약하고, 너무 길면 모바일에서 이탈 가능성이 높다.

### 문답당 답변 기준

각 Q 답변:
- 기본 2~4문장
- 약 100~250자
- 복잡한 질문은 300자까지 허용
- 표가 필요한 질문은 답변을 짧게 쓰고 표로 보완

### 답변 구조

각 문항은 가능하면 아래 순서로 작성한다.

1. 결론 한 문장
2. 기준 설명 1~2문장
3. 예외 또는 확인처 1문장
4. 필요 시 내부 링크 1개

### 표 또는 박스가 필요한 문항

글 1:
- 이의신청 기간과 접수처는 작은 표 가능
- 준비서류는 bullet 가능

글 2:
- 건강보험료 기준표 또는 핵심 기준표 필요
- 맞벌이 등 다소득원 기준은 bullet 가능
- 1차와 2차 중복 여부는 짧은 표 가능

글 3:
- 신청 채널 4종은 표 가능
- 사용지역 기준은 표 가능
- 카드사 링크는 별도 표 가능하나, 링크 유효성 확인 후 반영

### 톤

- Q&A 글은 합니다체로 통일
- 보도형 했다체와 섞지 말 것
- 단정 위험이 있는 답변은 "가능성이 있습니다", "확인이 필요합니다", "이의신청 대상이 될 수 있습니다" 톤 사용
- 그러나 공식 확정 사항은 명확하게 표현
  - 1차 지급자는 2차 중복 신청·지급 불가
  - 5/18 09:00 신청 시작
  - 이의신청 마감 7/17 18:00
